# Reference build

A front end reference build for a mobile phone retailer: new and graded preowned
handsets, trade in, instalment led pricing, and four languages with full right to
left support.

**This is a design and UX reference, not a production build.** There is no
backend. Nothing is stored, nothing is sent, and every price, stock count and
review is invented.

Produced by YAS Solutions LLC.

## Run it

    node server.js 4451

## What is in here

    index.html            storefront
    assets/css/           style.css, v5.css, v6.css, i18n.css
    assets/js/            main.js, i18n.js
    assets/img/           product, brand and flag imagery
    assets/fonts/         self hosted Arabic, Devanagari and Naskh webfonts

## Known limits

- No backend. Refreshing clears the cart. Forms confirm without sending.
- All commercial data is fictional.
- Interior photographs are stock images and are placeholders.
- Product imagery and brand marks are manufacturer assets.
